# 증강 슈팅 — 엔트리 간단판 (`증강슈팅_간단판.ent`)

웹 게임(index.html)의 핵심을 **엔트리 블록으로 다시 만든** 작품 파일이에요.
엔트리는 JavaScript를 실행할 수 없어서, 게임을 블록으로 새로 짰어요.

## 여는 방법

- **엔트리 웹사이트**: playentry.org → 만들기 → 작품 만들기 → 왼쪽 위 메뉴(파일) → **오프라인 작품 불러오기** → 이 `.ent` 파일 선택
- **엔트리 오프라인 프로그램**: 파일 → 열기 → 이 `.ent` 파일 선택

▶ 시작하기를 누르면 메뉴가 나와요.

## 들어 있는 것

| | 엔트리 간단판 |
|---|---|
| 메뉴 | 제목 스티커, 숨 쉬는 "게임 시작" 버튼, 조작법, 카드 도감(8장), 최고 기록, 둥실거리는 장식 |
| 일시정지 · 결과 | P · Esc 일시정지 (계속하기 / 메뉴로), 게임 오버 · 클리어 화면 (도달 웨이브, 점수, 최고 기록 · 신기록, 다시 하기 R / 메뉴로 M) |
| 상태창 | 왼쪽 위 갈색 패널: "챕터 · 웨이브", 체력바 (30% 이하면 빨강, 최대 체력이 늘면 번쩍), 점수 / 오른쪽 위: 가진 증강과 레벨 |
| 대미지 숫자 | 맞힐 때마다 숫자가 "뻥" 튀어나와 떠오르며 사라져요. 대미지가 클수록 큰 숫자. 흰색 = 보통, **노랑 = 큰 한 방** (20 이상), **빨강** = 내가 맞음, **초록** = 회복 / "최대 체력 +20" |
| 체력바 | 한 대라도 맞은 적은 머리 위에 체력바, 보스는 화면 위에 큰 "보스" 체력바 |
| 웨이브 | 10웨이브 (5 · 10웨이브는 보스, 12방향 탄막), 적: 기본 · 돌격형 · 사인파형 |
| 카드 | 증강 6개 (촉매, 3방향 탄, 복리 탄환, 시간 지연, 넉백, 분산 증폭) + 보급 2개 (세포 분열, 항상성) |

- 조작: 방향키 또는 WASD 로 이동, 총은 가장 가까운 적에게 자동 발사
- 웨이브를 깨면 체력 +10, 카드 3장 중 하나를 클릭 (또는 1 · 2 · 3 키)
- 웹 게임에 있는 코인 · 업그레이드 · 설정 · 나머지 적과 증강은 없어요
- 최고 기록은 작품을 ▶ 다시 시작하기 전까지만 남아요 (엔트리는 저장 기능이 없어요)

## 다시 만들기

블록은 손으로 놓은 것이 아니라 `tools/entry/build-ent.js` 가 만들어요.
숫자(속도, 체력, 웨이브 수 ...)는 그 파일 맨 위 상수를 바꾸고 다시 만들면 돼요.

```
NODE_PATH=$(npm root -g) node tools/entry/build-ent.js
```

- `tools/entry/blocks.js` : 엔트리 블록을 짧게 적는 도우미
- `tools/entry/art.js` : 그림 (게임과 같은 스티커 스타일)
- `tools/entry/assemble.js` : 작품 파일(project.json + 그림)로 묶기

엔트리에서 직접 블록을 고쳐도 돼요. 다만 그 뒤에 이 도구로 다시 만들면 직접 고친 내용은 사라지니 주의하세요.
