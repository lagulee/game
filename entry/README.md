# 증강 슈팅 — 엔트리 간단판 (`증강슈팅_간단판.ent`)

웹 게임(index.html)의 핵심을 **엔트리 블록으로 다시 만든** 작품 파일이에요.
엔트리는 JavaScript를 실행할 수 없어서, 게임을 블록으로 새로 짰어요.

## 여는 방법

- **엔트리 웹사이트**: playentry.org → 만들기 → 작품 만들기 → 왼쪽 위 메뉴(파일) → **오프라인 작품 불러오기** → 이 `.ent` 파일 선택
- **엔트리 오프라인 프로그램**: 파일 → 열기 → 이 `.ent` 파일 선택

▶ 시작하기를 누르면 메뉴가 나와요.

- 블록이 많아서 작품을 여는 데 시간이 좀 걸려요. 다 열린 뒤에 ▶ 를 눌러 주세요.
- 엔트리의 **부스트 모드는 끄고** 하세요. 켜면 한 프레임에 블록이 여러 번 돌아서 게임이 빨라져요.
- 맨 위의 `작품 안내` 오브젝트는 블록이 없는 빈 오브젝트예요. 작품을 열 때 큰 오브젝트의 블록을 먼저 그리느라 느려지지 않게 맨 앞에 두었어요.

## 들어 있는 것

| | 엔트리 간단판 |
|---|---|
| 그림 | 적 · 보스 · 카드 · 상태창 · 버튼은 **웹 게임의 그리기 코드로 그대로 찍어 낸 그림**이라 웹과 똑같아요 (눈이 8방향으로 따라오고, 맞으면 하얗게 번쩍) |
| 글씨 | 웹과 같은 검은 테두리 글씨. 글자 한 개씩 그림으로 붙여 쓰고, 웹에서 쓰는 글자 크기마다 따로 그려서 엔트리 무대에서도 깨지지 않아요 |
| 메뉴 | 흔들리는 제목 스티커, 숨 쉬는 "게임 시작" 버튼, 조작법, 카드 도감, 최고 기록, 둥실거리는 장식 |
| 웨이브 | **30웨이브**. 보스: 5 돌진 대장 · 10 분열의 왕 · 15 파동 군주 · 20 회전 포대 · 25 돌진 대장 + 분열의 왕 · 30 블랙홀 (웹과 같은 종류 · 수 · 패턴) |
| 적 | 기본 · 돌격형 (예고선 + 부르르) · 사인파형 · 분열형 (+ 작은 조각) |
| 연출 | 위에서 내려오는 웨이브 띠 (보스는 빨강), 바운스하며 나타나는 카드 (마우스를 올리면 들림), 파편, 대미지 숫자 (클수록 크게 · 흰/노랑/빨강/초록), 무적 깜빡임, 보스 체력바 |
| 일시정지 · 결과 | P · Esc 일시정지 (가진 증강 보기, 계속하기 / 다시 시작 / 로비로), 게임 오버 · 클리어 화면 (점수, 최고 기록, 신기록 스티커, 생존 시간, 잡은 보스) |
| 카드 | 증강 6개 (촉매, 3방향 탄, 복리 탄환, 시간 지연, 넉백, 분산 증폭) + 보급 2개 (세포 분열, 항상성). 웹과 같게 증강을 먼저 뽑고 모자라면 보급으로 채워요 (증강을 다 모으면 보급 2장), 체력이 40% 아래면 보급 1장은 꼭 |

- 조작: 방향키 또는 WASD 로 이동, 총은 가장 가까운 적에게 자동 발사
- 웨이브를 깨면 체력 회복, 카드 3장 중 하나를 클릭 (또는 1 · 2 · 3 키)
- 웹 게임에 있는 코인 · 업그레이드 · 설정 · 나머지 적과 증강은 없어요
- 최고 기록은 작품을 ▶ 다시 시작하기 전까지만 남아요 (엔트리는 저장 기능이 없어요)

## 설정 · 숫자 조절 · 디버그 모드 (만든 사람용)

메뉴 오른쪽 위 톱니 버튼 → 설정 창. 웹 게임과 같은 비밀번호를 넣어야 열려요 (작품을 ▶ 다시 시작할 때까지 기억).
비밀번호는 무대 아래 대답 칸에 쓰고 Enter, 그만두려면 "취소" 라고 쓰면 돼요.

- **숫자 조절**: 이동 속도, 시작 체력, 발사 간격, 총알 속도 · 대미지, 회복, 적 체력 · 대미지 · 속도 배율, 적 무리 간격 · 마릿수 (웹 조절판과 같은 이름 · 단위).
  줄을 누르고 새 값을 쓰면 바로 바뀌어요. 노란 줄 = 기본값과 다른 값. "모두 기본값", "잠그기" 도 있어요.
  이 17개 값은 엔트리 **실시간 변수** (`조절_이동속도` 등) 라서, 바꾼 값이 엔트리 서버에 저장돼요.
  작품을 다시 열어도, 다른 사람이 플레이해도 바뀐 값으로 돌아요 (난이도 조정을 게임 전체에 적용).
  - 실시간 변수는 **playentry.org 에 저장(온라인)한 작품**에서만 서버에 저장돼요. 내 컴퓨터에서 연 .ent 그대로나 저장 전에는 ▶ 를 멈추면 원래 값으로 돌아가요.
  - 처음 한 번: .ent 를 불러온 뒤 작품을 저장하고, 저장된 작품에서 ▶ → 설정 → 숫자 조절로 바꾸면 돼요.
- **디버그 모드**: 설정 창의 버튼 또는 <code>`</code> 키 (숫자 1 왼쪽. 웹의 F2 — 엔트리는 F2 키를 받을 수 없어요)

| 키 | 하는 일 (웹과 같다) |
|---|---|
| [ / ] | 이전 / 다음 웨이브로 바로 이동 |
| G | 증강 · 보급 지급 창 (증강 +1 / −1, 모두 삭제, 보급 바로 사용) |
| B | 보스 선택 창 (메뉴에서는 그 웨이브부터 새 게임) |
| Shift + 0 | 체력 가득 |
| I | 무적 켜기 / 끄기 |

웹의 Shift + C (코인 +1000) 는 엔트리판에 코인이 없어서 빠졌어요.

## 썸네일

`썸네일.png` 가 작품 대표 그림이에요. 작품을 열면 ▶ 를 누르기 전 무대에 이 그림이 보여서, 엔트리에 저장할 때 무대를 찍는 대표 그림으로도 쓰여요.

## 다시 만들기

블록은 손으로 놓은 것이 아니라 `tools/entry/build-ent.js` 가 만들어요.
숫자(속도, 체력, 웨이브 수 ...)는 그 파일 맨 위 상수를 바꾸고 다시 만들면 돼요.

```
NODE_PATH=$(npm root -g) node tools/entry/build-ent.js
```

- `tools/entry/blocks.js` : 엔트리 블록을 짧게 적는 도우미
- `tools/entry/sprites.js` : 웹 게임을 브라우저로 열어 그리기 함수로 그림을 찍어 내요 (그래서 웹과 똑같아요)
- `tools/entry/assemble.js` : 작품 파일(project.json + 그림)로 묶기

엔트리에서 직접 블록을 고쳐도 돼요. 다만 그 뒤에 이 도구로 다시 만들면 직접 고친 내용은 사라지니 주의하세요.
