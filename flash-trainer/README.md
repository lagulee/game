# 플래시 회피 훈련 (발로란트 눈뽕 피하기 연습)

발로란트의 플래시 수치(최대 눈뽕 · 윈드업)와 감도 공식(0.07°/카운트), 수평 FOV 103°를 재현한 1인칭 웹 게임이다.
플래시가 던져지는 소리를 듣고 **고개를 돌려 등지면** 눈뽕을 피할 수 있다.

- 비용 0원, 설치 · 빌드 단계 없음. Three.js r170은 `vendor/`에 들어 있다(MIT, 인터넷 연결 없이도 동작).
- 수치 근거와 출처: [`docs/flash-spec.md`](docs/flash-spec.md)

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭(file://)하면 브라우저가 코드를 막는다. 간단한 정적 서버로 연다.

```bash
cd flash-trainer
python3 -m http.server 8000      # 또는: node tools/serve.mjs
# 브라우저에서 http://localhost:8000/
```

GitHub Pages에 올리면 `…/flash-trainer/` 주소로 바로 열린다.

**권장 브라우저: 크롬 · 엣지.** 이 브라우저들만 raw 마우스 입력(`unadjustedMovement`)을 지원한다.
다른 브라우저나 지원하지 않는 OS에서는 일반 포인터 락으로 대체하고 화면 아래에 안내 문구를 띄운다.
이때는 Windows의 「포인터 정확도 향상」을 꺼야 발로란트와 감도가 같아진다.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 | 시점 (발로란트와 같은 감도) |
| WASD / Shift | 이동 / 걷기 |
| 좌클릭 | 사격 (누르고 있으면 연사). 봇과 레이나 눈을 맞힐 수 있다 |
| R | 재장전 / (감도 테스트) 0°로 초기화 |
| Esc | 설정 화면 |

## 모드

- **반복 훈련**: 플래시가 랜덤한 타이밍, 종류, 방향으로 계속 날아온다. 라운드마다 눈뽕 시간, 평균, 최고 기록, 반응 시간을 오른쪽 위에 표시한다.
  - 점수는 **눈뽕 지속시간(초)**이고 0초가 완벽 회피다. 동시에 여러 개가 터지면 겹치는 시간을 한 번만 센다.
  - 반응 시간은 투척 순간(투척음)부터 시점이 2° 이상 돌아가기 시작할 때까지다.
- **감도 테스트**: 화면 위에 누적 회전각, 바퀴 수, 누적 카운트, 이동 거리(cm)를 표시한다. 자 위에서 마우스를 `cm/360`만큼 밀어 정확히 360.0°가 되는지 확인한다.

## 설정 (localStorage에 자동 저장)

- DPI, 발로란트 감도 → eDPI, cm/360, 1카운트당 각도를 자동 계산한다.
- 다른 게임 감도 변환기: CS2 · Apex(yaw 0.022), 오버워치2(yaw 0.0066). `발로란트 감도 = 원본 × (원본 yaw ÷ 0.07)`
- 맵: **빈 훈련장**(기본)은 바깥벽과 멀리 있는 방향 기둥 4개뿐이라 "돌아서 피하기"만 연습한다. **구조물 맵**에서는 벽·상자·복도로 모서리 뒤 플래시와 벽 가림을 연습한다.
- 난이도: 플래시 종류, 던지는 거리, 윈드업 배율(1.0 = 실제 값), 동시 투척 수(1~3), 라운드 간격, 등 뒤 투척 허용.
- **터지는 시간 배율**(기본 0.7): 브리치를 뺀 모든 플래시의 "던진 뒤 터질 때까지" 시간(던지는 모션·비행·윈드업)을 줄인다. 1.0이 실제 발로란트 값이다. 기본값 0.7이면 커브볼은 0.6 s → 0.42 s에 터진다. 브리치는 실제 값을 유지한다.
- **사격 · 봇**: 총은 밴달이다(머리 160 · 몸 40 · 다리 34, 9.75발/s, 25발). 봇 체력은 150이라 머리 한 발, 몸 네 발에 쓰러진다.
  - **플래시와 함께 피킹**(기본): 플래시가 터지는 순간 폭발 지점 2~4 m 뒤에서 봇이 튀어나온다. 제한 시간 안에 못 잡으면 "당함"이다. 피하고 → 돌아서서 → 잡는 흐름을 연습한다.
  - **봇 난이도**: 쉬움(기본, 가만히 서 있음, 3 s) / 보통(1.5 m/s 무빙, 2 s) / 어려움(3 m/s 무빙, 1.2 s).
  - **사격장처럼 상주**: 봇이 계속 서 있고, 잡으면 0.6 s 뒤 다른 곳에 다시 나온다.
  - HUD에 처치 수, 명중률, 헤드샷 비율, 피킹 승리 수, 평균 처치 시간을 표시한다.
- 효과음 · 이명 볼륨, 디버그 표시(궤적과 폭발 지점 표시).

## 스펙 일치 점검 결과

`node --test tests/unit.test.mjs`(28개)와 `node tests/smoke.mjs`(실제 브라우저)로 확인했다.

| 항목 | 스펙 | 게임 | 확인 방법 |
|---|---|---|---|
| 감도 | Δ° = 카운트 × sens × 0.07 | 같음. 프레임과 무관(이벤트마다 즉시 반영, deltaTime 미사용) | 1카운트씩 12857번 보낸 결과와 한 번에 보낸 결과 동일 |

## 근사 구현 목록 (발로란트 공식 수치를 찾지 못한 부분)

모두 `src/config/flash.js`, `src/config/view.js`에 `[근사값]`으로 표시돼 있고 거기서 조정한다.

1. **각도 → 지속시간 곡선**: 30° 안에서는 100%, 110° 밖에서는 0%, 그 사이는 코사인 곡선. "정면은 최대, 옆은 감소(화면 밖도 부분 눈뽕), 등지면 없음"이라는 확인된 성질에만 맞췄다.
2. **거리 감쇠**: 출처끼리 말이 달라서 기본은 꺼 두었다(`BLIND.distance.enabled`).
3. **페이드 곡선과 약한 눈뽕의 페이드 길이**: 1 − u² 곡선을 쓰고, 페이드 길이는 √배율에 비례한다.
4. **던지는 모션 시간, 투사체 속도, 커브볼 곡률, 스카이 매 비행시간과 재사용 후 윈드업(0.5 s)**
5. **궤적**: 물리 시뮬레이션이 아니라 폭발 지점에서 거꾸로 계획한 경로다. 그래서 거리와 방향 설정이 정확히 지켜진다. 요루와 케이/오의 튕김은 반사 법칙으로 계산한다.
6. **레이나 눈**: 1.6 s를 "눈이 근시를 거는 시간"으로 해석했다. 바라보는 각도 55° 안이고 가려지지 않으면 근시다. 한 발 40 피해로 2발이면 파괴된다.
7. **소리**: 전부 합성음이다. 발로란트에 이명이 있다는 출처는 찾지 못했다. 이명은 CS:GO 레퍼런스(약 2.6 kHz)로 넣었고 설정에서 끌 수 있다.
8. **이동 속도 6.75 m/s, 눈 높이 1.6 m, 맵**: 연습용 단순 구조다. 빈 훈련장에는 근처에 벽이 없어서 요루와 케이/오는 바닥에 튕긴 뒤 터진다(근처에 벽이 있으면 벽에 튕긴다).
9. **동시 투척**은 0~0.3 s씩 어긋나게 던지고, 반응 시간 기준은 2°다. 둘 다 훈련 규칙이다.
10. **터지는 시간 배율 0.7(기본)은 실제보다 빠른 훈련용 값이다.** 실제 수치로 연습하려면 1.0으로 바꾼다.
11. **총**: 피해량 · 연사 속도 · 탄창만 실제 값이다. 탄 퍼짐은 발로란트의 고정 반동 패턴이 아니라 "연사할수록 넓어지는 원뿔"로 단순화했다(처음 3발은 정확). 이동 사격 퍼짐, 재장전 2.5 s, 봇 크기와 무빙(±1.0 m, 속도는 난이도별)도 근사값이다. 봇은 실제로 조준하지 않고, 제한 시간이 지나면 "당함"으로 처리한다.

## 알려진 한계

- 브라우저에서는 OS 마우스 가속이 남아 있을 수 있다(raw 입력을 지원하지 않는 브라우저). 감도 테스트 모드로 실제 cm/360을 확인한다.
- 일부 크롬 + Windows 환경에서는 포인터 락 직후 마우스 이동값이 한 번 크게 튀는 버그가 보고된 적이 있다. 이 게임은 값을 거르지 않는다(정확도 우선).
- 이 환경의 네트워크 정책 때문에 공식 패치 노트를 직접 열지 못하고 검색 요약으로 확인했다. 최신 패치에서 수치가 바뀌면 `src/config/flash.js`만 고치면 된다.
