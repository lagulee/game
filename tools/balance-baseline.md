# 기준 표 (증강 14개·보급 5개 추가 전)

- 언제: 증강 9개·보급 2개였을 때, 게임 코드 기본값 (만든 사람이 직접 플레이해서 마음에 든 상태)
  - 업그레이드 0 이면 5웨이브 보스에서 죽고, 공격력을 조금 올리면 보스를 아슬아슬하게 깨는 느낌
- 측정: `NODE_PATH=$(npm root -g) node tools/balance.js --runs 30 --levels 0,0/3,0/6,3,6,10,15,20,25,30`
- 새 봇(카이팅), 레벨마다 30판, 카드는 무작위. 고정 난수라 같은 코드면 언제 재도 같은 표가 나온다
- 숫자 원본: tools/balance-baseline.json (나중에 비교할 때 쓴다)
